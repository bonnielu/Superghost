## ✨ Features

- 🎮 Real-time multiplayer gameplay (2–6 players)
- ⚔️ Bluffing and challenge mechanics
- ⏱️ Turn timer
- 💬 Built-in chat and activity feed
- ⌨️ Keyboard shortcuts

---

## 🎮 How to Play

1. **Build the fragment** by adding one letter to either the left or right.
2. **Avoid completing** a valid English word.
3. **Bluff** if you're not completely sure what word the fragment will become.
4. **Challenge** the previous move if you believe no valid continuation exists.
5. **Lose all three lives**, and you're eliminated. The last remaining player wins.
